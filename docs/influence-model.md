# Модель влияния через коридоры ситё

Геометрическая модель по тексту «Введение в теорию влияния».

## Коридоры и поле

Для камня s и пункта p положим (x,y) = p − s. Для каждого направления (a,b) ∈ {−1,+1}² пункт входит в коридор, если ax ≥ 0, by ≥ 0 и |ax − by| ≤ 2. Оси входят в два квадранта. На расстоянии 1 или 2 вдоль оси камень даёт 2, на диагонали вне источника даёт 1, на расстоянии 3 вдоль оси даёт 0.

В каждом пустом пункте храним по четыре двоичных признака каждого цвета. Признак установлен, если хотя бы один реальный или разрешённый зеркальный источник покрывает пункт в этом направлении. B и W — числа установленных направлений каждого цвета. Итог I = B − W лежит от −4 до +4. Хранение B и W отдельно позволяет различать отсутствие влияния и борьбу за пункт.

## Крайняя диагональ у стены

На первой, второй и третьей линиях край отключает крайнюю диагональ каждого коридора, направленного от этого края вглубь доски. Если n — смещение от камня по нормали внутрь доски, а t — смещение вдоль края, отключаем направление при n ≥ 0 и |t| − n = 2. При n = 0 отключается только направление вглубь, поскольку общий осевой пункт входит и в соседний коридор. Например, для R10 правый край отключает вклад на K19 и K1, а в пунктах R12 и R8 сохраняется вклад соседнего коридора. Правило симметрично по четырём краям. В углу применяются ограничения обоих краёв. При зеркальном усилении участвует оставшаяся часть реального коридора, а отключённые направления источника не возвращаются через его зеркальные пары.

## Зеркало

Отражаем камень t относительно первой линии. Для каждой пары s,t из одной ортогонально связной цепочки, включая s=t, проверяем, что отрезок от s до отражения t пересекает первую линию в целочисленном пункте q, видимом из обоих реальных камней через их коридоры. Отражение t добавляет свои направления только в пунктах пересечения с коридорами s. Проверяем обе ориентации пары и четыре края. Применяем только одиночные отражения. Камни на рассматриваемой первой линии учитываем как реальные источники.

Контрольные случаи: одиночный камень на третьей линии даёт 4 в пункте прямо перед ним на первой линии. Два соседних камня на четвёртой линии не усиливаются. Три подряд усиливаются через пару крайних камней. Два камня с пробелом на четвёртой линии не усиливаются через эту пару, если принадлежат разным цепочкам.

## Дырки

Для камней A,B одного цвета берём D = d₁(A,B), где d₁ — манхэттенское расстояние. При D ≥ 2 средние пункты всех кратчайших путей удовлетворяют d₁(A,p)+d₁(p,B)=D и |d₁(A,p)−d₁(p,B)|≤1. В свободной геометрии дырка существует, если из каждого такого пункта оба камня видны через коридоры. С точностью до симметрий получаются смещения (1,1), (2,0), (2,1), (2,2), (3,0), (3,1), (4,0).

## Открытые вопросы

Нужны отдельные правила для смещений и поворотов ситё у края, влияния даме и глаз, ослабления из-за дырок и зеркального усиления групп из нескольких цепочек. Геометрическая карта вычисляется для любой расстановки. Исход конкретного ситё зависит от тактической позиции и порядка ходов.
